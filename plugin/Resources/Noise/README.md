Noise profiles for the bottom module. Drop WAV or AIFF files here (stereo or mono,
any sample rate, up to 30 s are used) and rebuild. They're listed in name order and
shown without a leading number: "01 vinyl.wav" shows as "vinyl". Each becomes a
seamless loop (its last half second is crossfaded into its start).

Note: the noise type is saved by its position in this list, so add new files at the
end (a higher number) once a version has shipped.
