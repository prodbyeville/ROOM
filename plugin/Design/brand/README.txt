ROOM brand assets
=================

mark/       the ROOM mark (the room box): thin version for 100 px and up,
            "small" version (heavier lines) for 64 px and below.
            SVG (transparent, scalable) + PNG, in black, red and off-white.
wordmark/   the "room" wordmark, SVG + PNG (2048 px wide), three colours.
lockup/     mark + wordmark side by side, SVG + PNG, three colours.
app-icon/   red rounded square with the mark: PNG 16-1024 px, .ico (Windows),
            .icns (Mac).
installer/  the art used in the Windows and Mac installers.

Colours
  red        #BA2727   (accent; #E24A4A for thin marks on dark)
  black      #0A0A0A   (window)
  off-white  #F5F3EF   (text)
  graphite   #2A2A2A

Type: Satoshi (Regular, Medium, Bold, Black).
